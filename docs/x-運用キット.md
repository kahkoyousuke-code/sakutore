# サクトレ X運用キット

> 目的：Xからの集客で ①PVを増やしAdSense/A8収益につなげる ②外部リンクを獲得してGoogleのクロールバジェット不足（インデックス未登録）を解消する。
> 前提：開始時点ではフォロワーほぼゼロ。**リンクを撒くだけでは伸びない**。下の3層構造で回す。

---

## 0. 大原則（これだけは守る）

1. **リンク付き投稿はリーチが落ちる。** Xは外部リンクを嫌う。リンクは「価値が伝わった後」か「リプ/ツリーの2投稿目」に置く。
2. **無名アカウントの単独投稿は誰も見ない。** 最初の1〜2ヶ月はリーチを"借りる"＝大手フィットネス垢へのリプが主戦場。
3. **毎日1つは「リンクなしの価値投稿」。** これでフォロワーが増える。フォロワーが資産。
4. **週2〜3回だけ「リンク付き投稿」。** ツール・診断・コラムへ誘導。撒きすぎない。
5. **継続 > 完璧。** 1日5分でいい。途切れさせない。

---

## 1. 運用アカウント：@MotMotsu（既存・そのまま使う）

新規ではなく既存の **[@MotMotsu](https://x.com/MotMotsu)** を主軸にする。判断理由：

- フォロワー **177人**（ゼロじゃない＝コールドスタートの壁を突破済み）
- ジャンルがフィットネスで一致、自由に使える垢
- **権威性が強い**：`フィジーク入賞 / 筋トレ歴15年 / 90kg→78kg減量`。フィットネスXは信頼が命。この実績は最大の武器なので、ツイートで積極的に使う（「入賞した私が初心者に言うと…」型）
- bioに3サイト（sakutore/sakumeshi/sakusuppu）記載済み・#claudecode あり＝設定はほぼ完成

### 設定で詰めるのはここだけ
- **固定ポストを設定**（§4-A の診断シェア、または §2-E の開発ログのうち一番伸びたもの）
- プロフィールのURL3つはOK。サクトレを最優先で見せたいので、可能なら**サクトレを先頭**に。
- アイコン/ヘッダーがまだなら、サクラ（`/sakura.png`）と「AI×筋トレ」が伝わる画像に。

## 4. すぐ使えるツイート・テンプレ集

### A. 診断シェア（固定ポスト候補・リンクOK）
```

```
→ 結果ページの「画像」ボタンでスクショDL→添付。**画像付きはリーチが伸びる。**

### B. ツール小ネタ（数字で釣る・週1〜2）

```
ベンチ60kgが5回上がる人の1RM（最大重量）は約 67.5kg。
"今の自分の限界" を知らずに組むメニューは効率が悪い。

ビッグ3の換算、ここで一発で出る👇
sakutore.vercel.app/rm-calculator
```
消費カロリー：
```
体重70kgの人がランニング30分で消費するカロリー、
だいたい何kcalか即答できる人は意外と少ない。

答え合わせ→ sakutore.vercel.app/calorie-calculator
```
適正重量：
```
筋トレ初心者が最初にやるべきは "重さ選び"。
軽すぎても重すぎても伸びない。

身長体重から適正重量を診断👇

### C. 知識1ツイート（リンクなし・毎日の主力）
コラム1本を1ツイートに圧縮。**価値を完結させる＝保存・RTされる＝フォロワー増。**

例（protein）：
```
プロテインの最適な量、結論：

・体重×1.5〜2g/日
・運動する日は多め
・1回で吸収できるのは20〜40g
・朝とトレ後が優先

"とりあえず飲む" より配分。これだけで変わる。
```
例（over40 / 40代）：
```
40代から筋トレ始める人へ。

20代と同じやり方は逆効果。
・週2回で十分（回復が遅い）
・重量より丁寧なフォーム
・睡眠とタンパク質が若い頃の倍重要

"歳だから" は始めない理由にならない。むしろ今がベスト。
```
例（women-muscle-slim / 女性）：
```
「筋トレすると脚が太くなる」は誤解です。

女性は男性ホルモンが少なく、ムキムキになりにくい。
むしろ筋肉がつくと → 代謝↑ → 引き締まって細く見える。

正しく鍛えるとスタイルは良くなる。怖がらなくて大丈夫。
```
→ このCツイートが伸びたら、**リプ欄に**「詳しくはこちら」でコラムリンクを置く（本文には貼らない）。

### D. リプで参戦（最重要・毎日2〜3件）
大手フィットネス垢／バズってる初心者の悩みツイートに、**売り込まず有益な補足だけ**返す。
```

## 7. これがSEOにも効く理由

- Xに貼ったリンクはGoogleにクロールされ、**「外部からの発見」=クロールバジェット不足の直接の解決策**になる（[[sakutore-seo-indexing]] の真因）。
- プロフィールURL＋たまのリンク投稿で、未登録の22ページが"発見"されやすくなる。
- バズらなくてOK。**継続的に外部にURLが存在する状態**そのものが効く。

## 8. やってはいけないこと（BAN・凍結リスク）

- 同じ文面の連投（スパム判定）→ テンプレは毎回少し変える
- リプ欄にURL連打 → bio経由に統一
- フォロー/アンフォロー連打、相互フォロー営業 → 凍結リスク
- 1日に大量投稿 → 1〜2投稿/日で十分
