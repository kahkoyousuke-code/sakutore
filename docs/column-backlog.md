# コラムのネタ帳

定期実行（Routine）で1本ずつ書いていくための候補リスト。

## 使い方

1. **上から未チェックのものを1つ選ぶ**。書けない理由があれば飛ばして次へ
2. 書いたら同じコミットで `- [x]` に変え、末尾に公開日とURLを書く
3. 思いついた候補は下の「候補プール」に足す。順番は検索需要の大きさ順にしておく

## 選ぶときの基準

- **既存37本と食い違う数字を書かない。** 数字を出す前に `src/lib/` に該当モジュールがあるか探す（CLAUDE.mdの表を見る）
- 新しい数字を作るときは、条件を固定した「サクトレの基準」としてモジュールに置く
- 既存記事と内容がかぶるなら、**角度を変えられるときだけ**書く（例：頻度の記事があるので「毎日やっていいか」は毎日派の疑問に絞る）
- 書いたら既存記事から内部リンクを1〜3本張る。張る先がない記事は、たいてい角度がずれている

## どれを先に書くかの基準

**競合が埋まっているクエリは、角度が良くても後回しにする。** 記事の質より、そのクエリが空いているかどうかが結果を決める。

同じ型・同じ品質で書いた2本が、2026-09-20のSearch Console実測でこうなった。

| 記事 | 結果 |
|---|---|
| `/column/squat-average` | 公開5日で **10.5位**。`スクワット 平均` で9.0位、少数のクエリに集中してサイト総クリックの半分を稼いだ |
| `/column/bench-press-average` | 11日で **24.7位**。11クエリに表示が散り、1つも上位に固まらない |

差は書き方ではなくクエリ側の混雑度だった。「BIG3の種目別」のような**括りで決めず、その言葉が検索結果で空いているかで決める**。

## このドメインが勝てる領域（2026-09-20・3ヶ月187クエリを全件確認）

**Googleはサクトレを「BIG3の重量目安のサイト」として評価している。** 8〜15位に入れているクエリは、例外なくBIG3の重量・レベル・体重比だった。

| 順位帯 | 中身 |
|---|---|
| **7〜15位** | `big3 レベル 表` 11.3／`ビッグ3 早見表` 9.5／`スクワット 平均` 9.0／`big3 250kg` 8.4／`big3 700kg` 8.4／`体重80キロ ビッグ3` 9.6／`スクワット 体重の1.5倍` 7.0／`筋トレ レベル 診断` 13.3 — **全部この系統** |
| **70〜100位** | `筋トレ タンパク質 量` 92／`筋トレする時間帯` 100／`背中 筋肉` 78／`筋トレ 消費カロリー` 99／`rm 換算表` 88／`筋トレ 痩せる` 82 |

つまり**領域から離れるほど、書いても70位台から始まる**。栄養・時間帯・部位別・カロリー・RM換算は、記事の質に関係なく現時点では勝てない。

判定の手順:

- 狙うクエリで**自サイトが既に8〜15位で出ている**＝領域内。書けば1ページ目に入りやすい
- **40位以下しか出ていない**＝領域外。後回し
- **1件も出ていない**＝判定材料がない。この場合は順位ではなく、**上の「勝てる領域」に隣接しているかで決める**
- すでに1ページ目下段（8〜12位）にいる既存ページがあるなら、**新記事より既存の押し上げのほうが費用対効果が高いことがある**（`/column/squat-average` の9.0位、`/weight-checker` の9.0位が該当）

## 次に書く候補（領域内・優先）

**専用ページが無いのに既に表示が出ているクエリ**から埋める。掘り残しがここに集中している。

- [ ] 女性のBIG3体重別早見【未計測・カニバリ注意】（`女性 ベンチプレス 平均`・`女性 スクワット 何キロ`・`女性 big3` を想定。`womenBenchRows` 等はモジュールにあるが、**今は3本の種目別記事の中の一節として散っているだけ**で、女性を軸にしたページが無い。ただし種目別3本が既に女性の数字を載せているので、**書く前に Search Console で「女性＋種目」のクエリがその3本のどれで出ているかを必ず確認する**。既に8〜15位で出ているなら新記事ではなくその記事の増強にする） **→ 2026-10-31 GSC確認済み**：直近28日（10/1〜10/28）で「女性」を含むクエリは `デッドリフト 女性 平均` の1表示（10位）だけ。種目別3本の女性の節は検索にほぼ出ておらず、押し上げる既存記事が無いので**新記事で書いてよい**。ただし書く前に WebSearch で `女性 ベンチプレス 平均`・`女性 big3` の上位を見て、大手やジム系メディアで埋まっていれば見送る

## 新記事を書かずに既存を押し上げる項目

判定手順の最後にある「既存の押し上げのほうが費用対効果が高い」に当たるもの。**新記事を書くとカニバるので、候補リストではなくこちらに置く。**

| クエリ | 順位 | 受け皿 | やること |
|---|---|---|---|
| `スクワット 体重の1.5倍` | **7.0位** | `/column/squat-average` | すでに7位。比率を軸にした新記事を作らず、この記事の中の「体重の1.5倍」の節を厚くする |
| `筋トレ レベル 診断` | **13.3位** | `/weight-checker` | 1ページ目に届きかけ。ツール側の見出しと説明文を「診断」の語に寄せる |
| `ビッグ3 早見表` / `big3 レベル 表` | 9.5／11.3位 | `/column/strength-standards` | ハブが既に上位。表の位置を上げるなど、ページ内の構成で押す |

## 見送り（理由つき）

- 朝トレと夜トレはどっちがいいか（2026-10-31 見送り）— `/column/women-training-timing` がすでに「筋トレは朝と夜どっち？｜時間帯別メリット比較表」として同じ問いに答えている。新記事はカニバるので書かない。`筋トレする時間帯` を取りにいくなら、その記事の押し上げで扱う

- ベンチプレス◯kgはすごいのか（2026-10-31 見送り・GSC確認済み）— 直近28日（10/1〜10/28）で「ベンチ」を含むクエリは計8表示・平均29.9位で、ネタ帳の前提だった `体重55kg ベンチプレス`・`ベンチプレス 10回 平均` などは消えていた。受け皿の `/column/bench-press-average` もページ全体で18表示・12.5位。同じ逆引き型の squat-weight-level（48表示・9.6位）と比べても需要がこちらに届いておらず、ベンチ系は競合が強いという前提どおり。逆引き記事を足すより、勝っている strength-standards（28日で1,108表示・17クリック＝サイト全体の6割）周辺に力を使う

- ベンチプレス◯kgはすごいのか / 女性のBIG3体重別早見（2026-10-29 保留のまま）— 判定に要る Search Console が定期実行の環境から見られないまま。候補プールの残り2件も、体組成計は abs-body-fat と重なり、フィジーク大会は筆者の大会の具体的な事実（大会名・準備期間など）が既存の記録に無く書けないので見送った。領域外リストから、重量の目安を `dumbbellStandards.ts` で出せて領域（重量目安）に寄せられる「肩を大きくする筋トレ」を書いた

- ベンチプレス◯kgはすごいのか / 女性のBIG3体重別早見（2026-10-26 保留のまま）— 判定に要る Search Console が定期実行の環境から見られないまま。候補プールの「筋トレとサウナ・入浴」を先に書いた。**候補プールは残り2件で、どちらも領域外。** 領域内の2件の判定（GSC）が出ないと、次からは領域外の記事が続くことになる

- ベンチプレス◯kgはすごいのか / 女性のBIG3体重別早見（2026-10-22 保留のまま）— 判定に要る Search Console が定期実行の環境から見られないまま。候補プールの「ジムでのマナーと器具の使い方」を、BIG3寄りの「パワーラックの使い方」に寄せて先に書いた

- ベンチプレス◯kgはすごいのか / 女性のBIG3体重別早見（2026-10-19 保留のまま）— squat-average の title を戻してから9日。判定に要る Search Console は定期実行の環境から見られないまま。候補プールの先頭「セット数と重量の決め方」を先に書いた

- ベンチプレス◯kgはすごいのか / 女性のBIG3体重別早見（2026-10-15 保留のまま）— squat-average の title を10/10に戻してから5日で、まだ判定できる期間ではない。女性版も Search Console の確認待ちのまま。候補プールの先頭「BIG3以外に何をやるか（補助種目の選び方）」を先に書いた

- ベンチプレス◯kgはすごいのか / 女性のBIG3体重別早見（2026-10-12 保留のまま）— squat-average の title を10/10に戻して切り分け中で、ベンチ版の前提（squat-average の判定）がまだ出ていない。女性版は Search Console の確認待ち。今回も候補プールの「握力が先に限界になる問題」を先に書いた

- ベンチプレス◯kgはすごいのか / 女性のBIG3体重別早見（2026-10-08 保留のまま）— ベンチ版は「デッドリフト版の結果と squat-average の10/10判定を見てから」、女性版は「書く前に Search Console で確認」が条件。どちらも定期実行の環境からは確認できないので、判定材料が無いときのルール（勝てる領域に隣接しているか）に従い、候補プールの「ベルトはいつから必要か」を先に書いた

- ベンチプレス◯kgはすごいのか / デッドリフト◯kgはすごいのか（2026-10-01 判断保留）— どちらも「スクワット版／デッド記事の順位を見てから」という条件付き。**定期実行のクラウド環境からは Search Console を見られない**（`.gsc/` は git 管理外で、認証情報も環境に無い）ため、条件を満たせているか自動実行側では判定できない。`npm run seo:fetch`／CSVを置ける環境で順位を確認してから、この2件をどちらかに振り分けてほしい

- 体重別BIG3の目安（2026-09-28 見送り）— `/column/strength-standards` に「体重別に見るBIG3の目安（50〜100kg）」が入り、体重ごとの3種目＋合計の表・比率1枚・女性の表まで揃った。新記事を立てると同じクエリでハブとぶつかる。`体重80キロ ビッグ3` は既にハブが9.6位なので、**新記事ではなくハブの押し上げ**で取る
