# コラムのネタ帳

定期実行（Routine）で1本ずつ書いていくための候補リスト。

## 使い方

1. **上から未チェックのものを1つ選ぶ**。書けない理由があれば飛ばして次へ
2. 書いたら同じコミットで `- [x]` に変え、末尾に公開日とURLを書く
3. 思いついた候補は下の「候補プール」に足す。順番は検索需要の大きさ順にしておく

## 選ぶときの基準

- **既存37本と食い違う数字を書かない。** 数字を出す前に `src/lib/` に該当モジュールがあるか探す（CLAUDE.mdの表を見る）
- 新しい数字を作るときは、条件を固定した「サクトレの基準」としてモジュールに置く
- 既存記事と内容がかぶるなら、**角度を変えられるときだけ**書く（例：頻度の記事があるので「毎日やっていいか」は毎日派の疑問に絞る）
- 書いたら既存記事から内部リンクを1〜3本張る。張る先がない記事は、たいてい角度がずれている

## どれを先に書くかの基準

**競合が埋まっているクエリは、角度が良くても後回しにする。** 記事の質より、そのクエリが空いているかどうかが結果を決める。

同じ型・同じ品質で書いた2本が、2026-09-20のSearch Console実測でこうなった。

| 記事 | 結果 |
|---|---|
| `/column/squat-average` | 公開5日で **10.5位**。`スクワット 平均` で9.0位、少数のクエリに集中してサイト総クリックの半分を稼いだ |
| `/column/bench-press-average` | 11日で **24.7位**。11クエリに表示が散り、1つも上位に固まらない |

差は書き方ではなくクエリ側の混雑度だった。「BIG3の種目別」のような**括りで決めず、その言葉が検索結果で空いているかで決める**。

## このドメインが勝てる領域（2026-09-20・3ヶ月187クエリを全件確認）

**Googleはサクトレを「BIG3の重量目安のサイト」として評価している。** 8〜15位に入れているクエリは、例外なくBIG3の重量・レベル・体重比だった。

| 順位帯 | 中身 |
|---|---|
| **7〜15位** | `big3 レベル 表` 11.3／`ビッグ3 早見表` 9.5／`スクワット 平均` 9.0／`big3 250kg` 8.4／`big3 700kg` 8.4／`体重80キロ ビッグ3` 9.6／`スクワット 体重の1.5倍` 7.0／`筋トレ レベル 診断` 13.3 — **全部この系統** |
| **70〜100位** | `筋トレ タンパク質 量` 92／`筋トレする時間帯` 100／`背中 筋肉` 78／`筋トレ 消費カロリー` 99／`rm 換算表` 88／`筋トレ 痩せる` 82 |

つまり**領域から離れるほど、書いても70位台から始まる**。栄養・時間帯・部位別・カロリー・RM換算は、記事の質に関係なく現時点では勝てない。

判定の手順:

- 狙うクエリで**自サイトが既に8〜15位で出ている**＝領域内。書けば1ページ目に入りやすい
- **40位以下しか出ていない**＝領域外。後回し
- **1件も出ていない**＝判定材料がない。この場合は順位ではなく、**上の「勝てる領域」に隣接しているかで決める**
- すでに1ページ目下段（8〜12位）にいる既存ページがあるなら、**新記事より既存の押し上げのほうが費用対効果が高いことがある**（`/column/squat-average` の9.0位、`/weight-checker` の9.0位が該当）

## 次に書く候補（領域内・優先）

**専用ページが無いのに既に表示が出ているクエリ**から埋める。掘り残しがここに集中している。

- [ ] スクワット◯kgはすごいのか（`スクワット 140kg` **13位**・`スクワット 180kg レベル` 22位・`スクワット 80kg 十分` 33位・`スクワット 130kg` 37位・`スクワット 170kg` 46位・`スクワット 60kg` 28位。重量を打ち込む検索。`squatRows` から「その重量が体重別に何レベルか」の逆引き表。`/column/squat-average` からリンク）
- [ ] 体重別BIG3の目安（`体重80キロ ビッグ3` **9.6位**・`体重65キロ ビッグ3` 11位・`体重別 big3` 9.9位・`big3 体重別 レベル` 10.8位。体重を軸にした早見。ハブは種目軸なので角度が違う）
- [ ] ベンチプレス◯kgはすごいのか（`体重55kg ベンチプレス` 16位・`ベンチプレス 10回 平均` 18位・`ベンチプレス 重量` 19位。スクワット版と同じ逆引き型。ただしベンチ系は競合が強いので、スクワット版の結果を見てから）
- [ ] デッドリフト◯kgはすごいのか（`デッドリフト レベル表` 40位・`デッドリフト 重量 目安` 67位・`デッドリフト 60kg` 64位。`/column/deadlift-average` が2026-09-18公開なので、**順位が落ち着く10月以降に判断**）
- [ ] BIG3のどれが弱いか（種目間バランス）【未計測・領域内隣接】（`ベンチプレス スクワット 比率`・`big3 バランス`・`デッドリフト スクワット 差` を想定。既存3本は種目ごとに縦に読む記事で、**3種目を横に並べて「自分はどこが凹んでいるか」を出す記事が無い**。`benchRows`／`squatRows`／`deadliftRows` の比率を同じレベルで割って「ベンチ1に対しスクワット1.5・デッド2.0」の基準表を作る。ハブ（`/column/strength-standards`）と合計（`/column/big3-total`）の両方からリンクできる）
- [ ] ダンベルプレス◯kgはどのレベルか（逆引き）【未計測・領域内隣接】（`ダンベルプレス 20kg`・`ダンベル 30kg すごい`・`ダンベルプレス 何キロ` を想定。`/column/dumbbell-weight` は「何kgを買えばいい？」＝**選び方の軸**なので、「持っている重量が何レベルか」の逆引きは角度が違う。`dumbbellStandards.ts` にデータがあるので新しい数字は不要。スクワット版の逆引きが当たった型をそのまま横に広げる形）
- [ ] 女性のBIG3体重別早見【未計測・カニバリ注意】（`女性 ベンチプレス 平均`・`女性 スクワット 何キロ`・`女性 big3` を想定。`womenBenchRows` 等はモジュールにあるが、**今は3本の種目別記事の中の一節として散っているだけ**で、女性を軸にしたページが無い。ただし種目別3本が既に女性の数字を載せているので、**書く前に Search Console で「女性＋種目」のクエリがその3本のどれで出ているかを必ず確認する**。既に8〜15位で出ているなら新記事ではなくその記事の増強にする）
- [ ] BIG3合計を上げるならどの種目か【保留・上と統合検討】（`/column/big3-total` が2026-09-21公開。合計の逆引きと角度が近いので、**デッドリフト版と同じく10月以降に順位を見てから判断**。なお1つ上の「どれが弱いか」と中身が重なる（弱点診断＝合計の伸ばし方）ので、**2本に分けず1本にまとめる前提**で考える）

## 新記事を書かずに既存を押し上げる項目

判定手順の最後にある「既存の押し上げのほうが費用対効果が高い」に当たるもの。**新記事を書くとカニバるので、候補リストではなくこちらに置く。**

| クエリ | 順位 | 受け皿 | やること |
|---|---|---|---|
| `スクワット 体重の1.5倍` | **7.0位** | `/column/squat-average` | すでに7位。比率を軸にした新記事を作らず、この記事の中の「体重の1.5倍」の節を厚くする |
| `筋トレ レベル 診断` | **13.3位** | `/weight-checker` | 1ページ目に届きかけ。ツール側の見出しと説明文を「診断」の語に寄せる |
| `ビッグ3 早見表` / `big3 レベル 表` | 9.5／11.3位 | `/column/strength-standards` | ハブが既に上位。表の位置を上げるなど、ページ内の構成で押す |

## 次に書く候補（領域外・後回し）

いずれも関連クエリが70〜100位か、表示ゼロ。**領域内の候補を消化しきってから**着手する。

- [ ] ~~プロテインは飲まないとダメ？食事だけで足りるか~~【重複リスク高・要再検討】（`筋トレ タンパク質 量` **92位**。ただし `/column/protein`（必要量と献立例）と `/column/protein-guide`（選び方と比較表）の2本が既にあり、「食事だけで足りるか」は protein の献立例と大きく重なる。書くなら**既存2本のどちらかに節を足す**ほうが筋が良い）

## 候補プール（順番未定）

- 握力が先に限界になる問題（パワーグリップ）※ 握り方の表＝ダブルオーバー／オルタネイト／フックグリップ／ストラップ。競技ではストラップ不可なので目安表の基準は素手、という軸で書ける
- ベルトはいつから必要か ※ `/column/squat-average` と `/column/deadlift-average` の両方に「体重の1.5倍あたりから」と既に書いてあり、**基準は揃っているのに装備を主役にしたページが無い**。ベルト／リストラップ／ニースリーブを「何kgから要るか」の1本にまとめられる。`/gear` への内部リンクにもなる
- BIG3以外に何をやるか（補助種目の選び方）※ 領域内から一歩外へ出る導線。BIG3の記事群からリンクを張れるのが強み
- セット数と重量の決め方（5×5・3×10などの型）※ `/rm-calculator` が95.9位＝RM換算そのものでは勝てていないので、**換算表ではなく「どう組むか」側から入る**
- 筋トレとサウナ・入浴
- ジムでのマナーと器具の使い方
- 体組成計の数字の読み方
- 大会に出るという選択肢（フィジーク）
