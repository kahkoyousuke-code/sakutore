# コラムのネタ帳

定期実行（Routine）で1本ずつ書いていくための候補リスト。

## 使い方

1. **上から未チェックのものを1つ選ぶ**。書けない理由があれば飛ばして次へ
2. 書いたら同じコミットで `- [x]` に変え、末尾に公開日とURLを書く
3. 思いついた候補は下の「候補プール」に足す。順番は検索需要の大きさ順にしておく

## 選ぶときの基準

- **既存34本と食い違う数字を書かない。** 数字を出す前に `src/lib/` に該当モジュールがあるか探す（CLAUDE.mdの表を見る）
- 新しい数字を作るときは、条件を固定した「サクトレの基準」としてモジュールに置く
- 既存記事と内容がかぶるなら、**角度を変えられるときだけ**書く（例：頻度の記事があるので「毎日やっていいか」は毎日派の疑問に絞る）
- 書いたら既存記事から内部リンクを1〜3本張る。張る先がない記事は、たいてい角度がずれている

## 次に書く候補

- [ ] プロテインは飲まないとダメ？食事だけで足りるか（`/column/protein` の必要量から逆算。食事だけで摂る現実的な献立）
- [ ] 肩を大きくする筋トレ（三角筋の前・横・後ろ。サイドレイズの重さは `dumbbellStandards.ts`）
- [ ] 腹筋を割る種目と回数（`/column/abs-body-fat` は体脂肪の話なので、こちらは種目編。部分痩せの否定は向こうへリンク）
- [ ] 筋トレ前後に何を食べるか（空腹でやっていいか、何分前か）
- [ ] 伸びが止まったとき（停滞期）の対処（`/column/motivation` はメンタル側なので、こちらは重量・種目・頻度の側）
- [ ] 朝トレと夜トレはどっちがいいか（`/column/women-training-timing` の男女共通版・別角度）
- [ ] 太れない人の増量（必要kcalの出し方。`fatConversion.ts` と `/calorie-calculator`）
- [ ] 自宅で背中を鍛える（`/column/chest-home` の背中版。器具なしの限界と `/column/pullup-progression` へ接続）
- [ ] 脚トレのやり方（`/column/hip-training` はお尻なので、こちらは前もも・もも裏中心）
- [ ] 腰が痛いときの筋トレ（やめる痛みと続けていい痛みの線引き）
- [ ] クレアチンは必要か（サプリはサクサプと役割が重ならない範囲で）
